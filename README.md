# Community-level diversity of viral counter-defensomes

Support wrapper scripts for Beavogui et al. (2026) BioRxiv.

## Description
Bacteria and phages have co-evolved tit-for-tat strategies to combat one another for survival. To overcome phage infection, bacteria have developed various defense systems (the defensome), and in response, phages have evolved a counter-defensome to inhibit or evade such defensive strategies. While significant progress has been achieved on mechanistic, structural and functional aspects of the defensome, the study of the phage counter-defensome is relatively new, with very limited information available on the diversity and distribution of these systems across complex environmental phageomes. In Beavogui et al., we performed a large-scale analysis of the counter-defensome of 50,595 DNA phage population genomes reconstructed from soil, marine, and human gut environments. Here we present the collection of wrapper scripts used in such work. 
[(Beavogui et al., 2026, BioRxiv)](https://www.biorxiv.org/content/10.1101/2023.08.12.553040v2). 

PLEASE NOTE: Our pipeline includes a set of wrapper shell scripts that allow to reconstitute the major analyses steps of this publication. However, this pipeline requires multiple dependencies, which have to be installed prior to its use. 

## Sections
Details on the requirements and usage of all shell wrapper scripts can be accessed by **scriptname -h (or -help)**.

### 1) Viral identification, genome quality assessment, dereplication and annotation
* **GO_PhaBOX2.sh** identifies viral contigs using [PhaBOX2](https://doi.org/10.1093/bioadv/vbad101). Takes in the absolute path of the folder containing the fasta file(s) with extension \*\.fna, the absolute path of the folder for the output results, and the path of the PhaBOX2 database.
* **GO_CheckV.sh** performs the quality assessment of each viral genome using [CheckV](https://www.nature.com/articles/s41587-020-00774-7). Takes the absolute path of the folder containing the fasta file(s) with extension \*\.fna, the absolute path of the folder for the output results, and the path of the CheckV database.
* **GO_dRep.sh** performs the dereplication of genomes using [dRep](https://pubmed.ncbi.nlm.nih.gov/28742071/). Takes in the absolute path of the folder containing the fasta file(s) with extension \*\.fna, the absolute path of the folder for the output results, and the minimum sequence length.
* **GO_Prokka.sh** performs the annotation of each genome using [Prokka](https://pubmed.ncbi.nlm.nih.gov/24642063/). Takes in the absolute path of the folder containing the fasta file(s) with extension \*\.fna, and the absolute path of the folder for the output results.

### 2) Taxonomic assignment and viral morphology
* **GO_Kaiju.sh** performs the taxonomic classification of viral contigs using [Kaiju](https://www.nature.com/articles/ncomms11257). Takes the absolute path of the folder containing the fasta file(s) with extension \*\.fna, the absolute path of the folder for the output results, the taxonomy files nodes.dmp and names.dmp, and the Kaiju database.
* **GO_vConTACT3.sh** performs the taxonomic classification and gene-sharing network analysis of viral genomes using [vConTACT3](https://www.nature.com/articles/s41587-025-02946-9). Takes a nucleotide multifasta file with extension \*\.fna as input, the absolute path of the folder for the output results, and the path of the vConTACT3 database.
* **GO_VPF_Class.sh** performs the taxonomic classification of unclassified viral genomes using [VPF-Class](https://pmc.ncbi.nlm.nih.gov/articles/PMC8830756/). Takes a nucleotide multifasta file with extension \*\.fna as input, the absolute path of the folder for the output results, and the VPF-Class data index.
* **GO_iPHoP.sh** predicts phage hosts using [iPHoP](https://journals.plos.org/plosbiology/article?id=10.1371/journal.pbio.3002083). Takes the absolute path of the folder containing the fasta file(s) with extension \*\.fna, the absolute path of the folder for the output results, and the path of the iPHoP database.
* **GO_MMseqs2.sh** performs protein similarity searches against the RefSeq viral database using [MMseqs2](https://www.nature.com/articles/nbt.3988). Takes a protein multifasta file with extension \*\.faa as input, a reference protein multifasta file with extension \*\.faa, an output prefix, and a temporary folder.
* **GO_DIAMOND.sh** performs protein similarity searches against a protein database using [DIAMOND](https://www.nature.com/articles/s41592-021-01101-x). Takes the absolute path of the folder containing the fasta file(s) with extension \*\.faa, the absolute path of the folder for the output results, and the path of the DIAMOND database.

### 3) Identification of anti-MGE defense and counter-defense genes / systems
* **GO_DefenseFinder.sh** detection of anti-MGE defense genes / systems by [DefenseFinder](https://pubmed.ncbi.nlm.nih.gov/35538097/). Takes in the absolute path of the folder containing the fasta file(s) with extension \*\.faa, as well as the absolute path of the folder for the output results.
* **GO_AntiDefenseFinder.sh** detects anti-defense genes and systems using [AntiDefenseFinder](https://doi.org/10.1093/nar/gkae1171). Takes the absolute path of the folder containing the fasta file(s) with extension \*\.faa, as well as the absolute path of the folder for the output results.
* **GO_dbAPIS.sh** detects anti-defense proteins using the [dbAPIS framework](https://doi.org/10.1093/nar/gkad932). Takes the absolute path of the folder containing the fasta file(s) with extension \*\.faa, the absolute path of the folder for the output results, the dbAPIS HMM database, the APIS DIAMOND database, and the dbAPIS parsing script.

### 4) Biogeography and transcriptome
* **GO_vOTU_processing.sh** identification, quality filtering, header re-annotation, and dereplication of viral contigs. It takes an input directory of FASTA files and a CheckV database path. It assesses viral contig quality using [CheckV](https://www.nature.com/articles/s41587-020-00774-7), extracts high-quality viral sequences, and dereplicates viral genomes at 95% average nucleotide identity and 85% coverage using [dRep](https://academic.oup.com/ismej/article/11/12/2864/7537826).
* **GO_MAGs_processing.sh** quality evaluation, filtering, and dereplication of metagenome-assembled genomes (MAGs). It takes an input directory containing genome FASTA files and a target file extension. It evaluates genome completeness and contamination using [CheckM](https://genome.cshlp.org/content/25/7/1043), selects high-quality MAGs with completeness > 90% and contamination < 10%, and dereplicates the selected MAGs at 95% average nucleotide identity using [dRep](https://academic.oup.com/ismej/article/11/12/2864/7537826).
* **GO_reads_QC.sh** quality filtering, ribosomal RNA depletion, read repair, and concatenation of paired-end FASTQ reads. It takes a directory containing paired-end FASTQ files and a path to a reference rRNA database. It performs adapter trimming and quality filtering using [fastp](https://academic.oup.com/bioinformatics/article/34/17/i884/5093234), depletes ribosomal RNA reads using [SortMeRNA](https://academic.oup.com/bioinformatics/article/28/24/3211/246053), re-synchronizes paired-end non-rRNA reads using [BBTools](https://jgi.doe.gov/data-and-tools/software-tools/bbtools/), and concatenates clean non-rRNA reads into master forward and reverse FASTQ files.
* **GO_reads_pseudomapping.sh** transcript expression quantification and per-base sequence coverage calculation for non-rRNA reads. It takes a dataset prefix, reads directory containing non-rRNA FASTQ files, a Kallisto index file, thread count, memory allocation, and library strandness settings. It quantifies gene expression and outputs pseudoalignments using [Kallisto](https://www.nature.com/articles/nbt.3519), sorts, indexes pseudobam files, and computes base-level coverage depth using [SAMtools](https://academic.oup.com/bioinformatics/article/25/16/2078/204688).
* **GO_defense_expression_HKmedian.sh** expression normalization and summary reporting of defense and counter-defense systems relative to bacterial housekeeping gene medians. It takes Kallisto abundance tables, SAMtools depth tables, [DefenseFinder](https://www.nature.com/articles/s41467-022-30269-9) DefenseFinder outputs, viral and bacterial CDS FASTA files, HMM reference lists, Prokka/Prodigal annotation tables, a housekeeping gene list, and coverage/read filtering thresholds. It calculates reads per kilobase (RPK) from Kallisto data, calculates coverage using SAMtools depth data, normalizes gene expression ratios against median bacterial housekeeping gene RPKs based on DefenseFinder system annotations, and generates structured report summaries across biogroups, subtypes, and defense systems.

### 5) Gene neighborhood analysis
* **GO_InterProScan.sh** performs the functional annotation of proteins using [InterProScan](https://doi.org/10.1093/bioinformatics/btu031). Takes the absolute path of the folder containing the fasta file(s) with extension \*\.faa, and the absolute path of the folder for the output results.
